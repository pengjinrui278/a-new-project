# 对话工作台 · 本地试用

需要 Node.js 24 或更高版本。运行 `node server.mjs`，打开 http://127.0.0.1:4177/ 注册独立账号并填写自己的博客名称。只监听本机，笔记保存在 .data/workbench.sqlite。

在 Edge 的 edge://extensions（或 Chrome 的 chrome://extensions）启用开发人员模式，加载本项目的 extension 文件夹。打开 DeepSeek 网页自行登录，刷新后选中一段回答。

- 展开追问：补充原题或问题，浏览器尝试并排两个窗口。确认右侧是新会话，点击“填入分支上下文”后自行发送。不会自动发送；保留原窗口。若无法识别输入框，尝试将上下文复制到剪贴板。
- 存为笔记：打开本机文章库，已登录会直接生成私人笔记；未登录先登录。支持标准 MathML 和带 MathML 的 KaTeX 摘录，其他公式结构须逐站验证。
- 文章库：可改名称、标题和批注，可删除笔记；通过来源链接回原会话。尚未提供公式编辑面板、同页嵌入、桌面客户端及公网部署。

运行 `node verify.mjs` 可检查登录、笔记持久化、公式数据和账号隔离，会在本地创建合成测试账号。DeepSeek 实际选文、窗口布局、填入并发送需登录后的浏览器验收。
